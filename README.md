# FarooqStars — weekly sign reels (Bolte Sitare)

Every Monday GitHub makes 12 English videos — one per Western sign — and sends them to farooqstars.com.
Studio 2 on the site posts them: a Facebook Reel on Bolte Sitare and a TikTok post on @boltesitare, two signs a day.

* Pictures and words: `https://farooqstars.com/reel-render.html` (the site's own readings engine).
* Voice: Kokoro (free, runs on GitHub), voice `am_michael`, speed 1.1.
* Run by hand: Actions → *Weekly reels (Bolte Sitare)* → Run workflow (`signs` empty = all 12).
* Secret needed: `FS_REEL_KEY` (Studio 2 → 🔑 GitHub upload key).
